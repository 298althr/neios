02 · The governed loop

Every request crosses eight control points

The code runs the show — the model only drafts inside the envelope the code defines.

one call path — UI, script, or MCP client, same eight gates
03 · Request → Context

Intake is structured before the model is touched

APSOS pack
WHO requests · WHAT work type + items · WHY purpose + criticality · WHEN urgency
Missing fields
Required APSOS paths are checked up front — "bill the patient" stops here, flagged, before any model call.
04 · Policy

A deterministic gate runs before the model

Allowed
Work type in the Role Card's allowed actions → proceeds to the model.
Blocked
"Wire ₦200,000 to the supplier account" — 0 ms, no model call. The refusal is still audited.
05 · Model

Only now does N-ATLaS run

Real endpoint, real request IDs — openai-compat any OpenAI-compatible server

06 · Result

Output is parsed, validated, repaired — not trusted

Schema
Strict invoice_draft JSON — malformed output gets one bounded retry.
Deterministic repair
Model wrote 20×8,000 as ₦1,600,000 → validator corrected to ₦160,000. Repairs are named, not silent.
07 · Evidence

Every field carries provenance

input_fact
Verified against the request — quantities, named parties.
model_derived
The model's contribution — descriptions, line structure.
system_derived
Computed by code — totals, dates, hashes.
08 · Approval

Consequential output waits for a person

Lane-2 drafts hold at pending_approval — content never grants authority.

! APPROVAL draft pending human approval (lane 2)
→ human approved → linked audit record: finalState "approved"
