# 11-decisions

Architecture/ engineering decisions are ADRs in `engineering/decisions/`.
The index of record is `engineering/DECISION-LOG.md`.

Rules:
- Every consequential decision has an ADR (template: `engineering/_templates/ADR-TEMPLATE.md`).
- Corrections supersede (`SUPERSEDED` + `superseded_by`) — history is never erased.
- A discussion is not a decision; use `engineering/deliberations/` first when positions conflict.
