finalState=pending_approval | approval=required | (never executed — human lane holds)

>>> tools/call neios_pending_approvals (0.0s)
pending count=54 (s1 pending: true)

>>> tools/call neios_record_decision (0.0s)
decision recorded: true approved

>>> tools/call neios_get_request (0.0s)

>>> tools/call neios_audit_tail (0.0s)

Read: tool calls 1–2 hit the real model (seconds of latency, real drafts). Call 3 blocked in 0 ms — deterministic policy fires before any inference. The injection attempt produced a draft but stopped at pending_approval — no tool can execute it.

4. API call sample — what the adapter actually sends

Source: packages/natlas-adapter/src/openai-compat.ts

GET  {NATLAS_BASE_URL}/models                    → first served model id (e.g. NCAIR1/N-ATLaS)
POST {NATLAS_BASE_URL}/chat/completions          → {model, messages:[system invoice-v1, user request],
                                                    temperature fixed, stream:false}

5. ASR integration — official NCAIR1 checkpoints

Source: services/natlas-asr/ · local FastAPI shim, official /v1/audio/transcriptions shape

  • NCAIR1/NigerianAccentedEnglish, NCAIR1/Hausa-ASR, NCAIR1/Yoruba-ASR, NCAIR1/Igbo-ASR — all four loaded and verified end-to-end on a consumer RTX 4060 (8 GB).
  • Spoken requests in English/Pidgin, Hausa, Yoruba and Igbo are transcribed locally, then enter the identical governed pipeline as typed requests (visible in the demo video, chapter 3).

6. Endpoint status & file manifest

Live runs used N-ATLaS Q4_K_M on a rented GPU, since stopped — compute budget exhausted; no hosted N-ATLAS API exists yet. The adapter is endpoint-agnostic: set NATLAS_BASE_URL and the full suite re-runs. With an organiser-provided endpoint, results can be returned within a day. Without one, pnpm --filter @neios/mcp test exercises the entire governed path against a stub provider.
